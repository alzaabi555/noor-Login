# ترقية بوابة نور إلى PWA

1. انسخ الملفات إلى جذر المستودع.
2. شغّل `python apply_pwa.py` داخل نسخة المستودع، ثم ارفع الملفات المعدلة.
3. لا يغيّر التحديث رابط Apps Script الحالي.
4. لا يخزن Service Worker طلبات POST أو ردود الطلاب أو جلسة الإدارة.
5. عند تحديث التطبيق غيّر `CACHE_NAME` في `service-worker.js` إلى v2 ثم v3 وهكذا.
