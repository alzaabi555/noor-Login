# بوابة ولي الأمر لمنصة نور - الإصدار 3

- حُذفت صفحة الإدارة ونظام رموز التحقق.
- التحقق أصبح بالرقم المدني لولي الأمر والطالب وتاريخ ميلاد الطالب.
- أنشئ ورقة باسم `Students` والصق ترويسة `Students-template.csv`.
- خزّن تاريخ الميلاد في العمود `birthDate` بصيغة `YYYY-MM-DD`، واضبط الأرقام المدنية كـ نص عادي.
- ضع معرف الجدول في `initializeSystem` داخل `Code.gs` وشغّل الدالة مرة واحدة.
- انشر Apps Script كإصدار جديد ثم حدّث `API_URL` في `login.html` إذا تغير رابط `/exec`.
- ارفع ملفات الواجهة إلى GitHub Pages، واحذف `admin.html` و`admin-manifest.webmanifest` من المستودع.
- غيّر كلمة مرور الإدارة القديمة إذا كانت مستخدمة في أي خدمة أخرى لأنها ظهرت سابقًا داخل الكود.
